3. MAIN SYSTEM MODULES

1. Authentication Module
This module manages user access to the system. Users can sign in according to their role, such as Public User, Warga UTHM, Lab Supervisor, Cluster Admin, or Super Admin. New public users can register through the Sign Up page, while existing users can log in using their registered credentials.

2. Account Recovery Module
This module allows users to recover access to their account if they forget their password. Users can request a password reset, receive a verification code through email, and create a new password.

3. Dashboard / My Booking Module
This module provides the main landing page after login. Public users and Warga UTHM users can view their booking records, while administrators can view booking activity and system overview information based on their access level.

4. Laboratory Browsing Module
This module allows users to view available laboratory clusters and select a laboratory. Users can review laboratory details before proceeding to check availability and make a reservation.

5. Laboratory Availability Module
This module displays the selected laboratory schedule. Users can view available dates, unavailable dates, booked slots, maintenance status, and available time slots before continuing with a reservation.

6. Laboratory Booking Module
This module allows users to submit a laboratory reservation. Users can select a laboratory, choose a booking date and time slot, enter reservation details, include equipment or chemical requirements if needed, and submit the booking for approval.

7. Group Booking Module
This module supports recurring class or lab session bookings. Authorized users, such as lab supervisors, can create or edit group bookings by setting the number of weeks, session days, laboratories, times, and booking type.

8. Booking History Module
This module allows users to review their previous and current bookings. Users can check booking details, booking status, and related reservation information.

9. Booking Receipt Module
This module generates a booking receipt for submitted reservations. The receipt can be used as a record of the booking details, including booking ID, laboratory, date, time, user details, and status.

10. Booking Management Module
This module is used by authorized staff to manage booking requests. Lab Supervisors can approve or reject bookings for assigned laboratories. Cluster Admins can monitor bookings within their cluster, while Super Admins can manage bookings across the system.

11. Laboratory Management Module
This module manages laboratory information. Admin users can view, add, or update laboratory details such as laboratory name, cluster, supervisor assignment, capacity, and related lab information. Lab Supervisors can view and manage laboratories assigned to them.

12. Cluster Management Module
This module manages laboratory clusters. It allows authorized admin users to create or manage clusters used to group laboratories under PPMKCP.

13. Supervisor Assignment Module
This module supports the assignment and review of lab supervisors. Admin users can view supervisors by cluster and check the laboratories assigned to each supervisor.

14. Asset Management Module
This module manages laboratory assets and equipment. Authorized users can view assets by laboratory and update asset information, making it easier to track equipment availability and laboratory resources.

15. User Management Module
This module is available to admin users for managing system users. Admins can view, filter, add, and edit users by user type, including Public User, Warga UTHM, Lab Supervisor, Cluster Admin, and Super Admin, depending on their permission level.

16. Report Analytics Module
This module provides reporting and analysis for laboratory bookings. Authorized users can view booking statistics, filter reports by date, laboratory, cluster, or booking status, and monitor system usage based on their access scope.

17. Profile Management Module
This module allows users to review and update their personal information, such as name, email, phone number, IC number, and other profile details.

18. Notification Module
This module supports system notifications related to booking activities. Users can receive updates about booking submissions, approvals, rejections, cancellations, and other relevant system actions.

19. Calendar Export Module
This module allows users to export or add booking information to a calendar, helping users keep track of approved reservation dates and times.

20. Role-Based Access Control Module
This module ensures that each user can only access functions allowed for their role. Public users and Warga UTHM users can make and view bookings, Lab Supervisors manage assigned laboratories and bookings, Cluster Admins manage information within their cluster, and Super Admins have full system access.
